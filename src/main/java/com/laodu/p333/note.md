# 最终总结（忘不掉版）

---

## 一、核心就一句

`compareTo` 只回答一个问题：

> **我要不要排他后面？**


| 返回值   | 意思           |
| -------- | -------------- |
| **正数** | 要，我往后站   |
| **负数** | 不要，我往前站 |
| **0**    | 一样，随便     |

**正数 = 往后站，负数 = 往前站。** 就这个。

---

## 二、升序降序怎么定

拿 **`this` 大、`o` 小** 的情况看：

- 返回**正数**（我往后站）→ 大的在后 → **升序**
- 返回**负数**（我往前站）→ 大的在前 → **降序**

口诀：

> **大正升，大负降。**
> （`this` 大时返回正 = 升序，返回负 = 降序）

---

## 三、代码模板

```java
// 升序：this 大时返回正 → this - o
return this.age - o.age;

// 降序：this 大时返回负 → o - this
return o.age - this.age;
```

推荐安全写法：

```java
return Integer.compare(this.age, o.age);   // 升序
return Integer.compare(o.age, this.age);   // 降序
```

---

## 四、忘了怎么办：代入法

拿两个数代进去：

```java
this = 30（大）, o = 18（小）
```

算你的表达式：

- 结果**正** → 30 往后站 → 大的在后 → **升序**
- 结果**负** → 30 往前站 → 大的在前 → **降序**

**大正升，大负降。** 算一次就出来了。

---

## 五、复杂表达式

不用管内部，只问一句：

> **`this` 大时，它返回正还是负？**

- 正 → 升序
- 负 → 降序

例：

```java
this.age > o.age ? 1 : -1     // this大时返回1（正）→ 升序
this.age > o.age ? -1 : 1     // this大时返回-1（负）→ 降序
(this.age - o.age) * -1       // this大时得负数 → 降序
```

---

## 六、一张图记住

```
compareTo 问：我要排后面吗？
        正数 = 要 → 往后站
        负数 = 不要 → 往前站

升序 = 大的往后站 = this大时返回正 = this - o
降序 = 大的往前站 = this大时返回负 = o - this
```

---

## 七、最终口诀（背这一句）

> **正数往后站，负数往前站；大的往后是升序，大的往前是降序。**

或者更短：

> **大正升，大负降。**

忘了就代入 `this=30, o=18` 算一下，看正负。
