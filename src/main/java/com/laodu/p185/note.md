# Java 类型转换笔记（无歧义版）

## 0. 核心结论

> **对象实际类型永远不变，引用声明类型可变。**
> **编译期：排除“必然失败”的转换，能放行就放行。**
> **运行期：JVM 用实际对象做最终检查。**

---

## 1. 对象与引用

```java
Child c = new Child();
Parent p = c;
I i = c;
```

- 只有一个对象，实际类型永远是 `Child`。
- 有三个引用，声明类型分别是 `Child`、`Parent`、`I`。
- 转型改变引用的声明类型，不改变对象的实际类型。


| 概念     | 看哪里           | 谁看       |
| -------- | ---------------- | ---------- |
| 声明类型 | 变量声明         | 编译器     |
| 实际类型 | `new` 出来的对象 | JVM 运行时 |

---

## 2. 祖先链

每个类型自身只记录**直接父类**和**直接实现的接口**。祖先链是从当前类型出发，顺着直接父类/直接接口逐级往上走，能到达的所有类型。

```java
class A {}
class B extends A {}
class C extends B {}

C 的祖先链：C → B → A
```

接口同理：

```java
interface I {}
interface J extends I {}
class P implements J {}
class Q extends P {}

Q 的祖先链：Q → P → J → I
```

**关键：编译器沿祖先链逐级走，不是搜索第三方类。**

---

## 3. 编译期规则

写 `T t = (T) x;`，`S` 是 `x` 的声明类型。

### 第一步：继承链是否连通


| 判断                   | 结果       | 性质                         |
| ---------------------- | ---------- | ---------------------------- |
| `T` 在 `S` 的祖先链上  | 放行       | 向上转型，自动，安全         |
| `S` 在 `T` 的祖先链上  | 放行       | 向下转型，需强转，运行时检查 |
| 两者都不在对方祖先链上 | 进入第二步 | —                           |

**第一步放行，编译期结束，进入运行期。**

### 第二步：排除法（前提：无父子关系）

此时已知：`T` 不在 `S` 的祖先链上，且 `S` 不在 `T` 的祖先链上。


| 条件                                        | 结果     | 理由                             |
| ------------------------------------------- | -------- | -------------------------------- |
| `S` 和 `T` 都是类                           | **报错** | 单继承，不可能有共同子类         |
| `S` 是 final 类，且 `T` 不在 `S` 的祖先链上 | **报错** | final 无子类，“子类可能”被堵死 |
| `T` 是 final 类，且 `S` 不在 `T` 的祖先链上 | **报错** | 同上                             |
| 其余（有接口参与，未被 final 堵死）         | **放行** | 语言规则允许“可能存在共同子类” |

**第二步放行，编译期结束，进入运行期。**

> **“放行”= 编译器不再报错，生成字节码。运行期还要过 `checkcast` 这一关。**

---

## 4. “潜在”的含义

“潜在”**不是**“编译器知道某个类实际存在”，而是“**语言规则没有排除这种可能性**”。

```java
interface I {}
interface J {}

I i = null;
J j = (J) i;   // 编译通过
```

代码里没有类同时实现 `I`、`J`。编译器不搜索。它只看：接口 vs 接口，未被 final 堵死，“可能存在一个类同时实现两者”，放行。

```java
final class A {}
interface I {}

A a = new A();
I i = (I) a;   // 编译报错
```

编译器不搜索。它只看：`A` 是 final，`I` 不在 `A` 的祖先链上，“子类可能”被堵死，报错。

---

## 5. 运行期规则

编译通过后，JVM 执行 `checkcast`，只看 `x` 指向的实际对象：


| 条件                   | 结果                 |
| ---------------------- | -------------------- |
| `x == null`            | 成功                 |
| 实际对象`instanceof T` | 成功                 |
| 否则                   | `ClassCastException` |

**JVM 完全不看声明类型 `S`。**

```java
Parent p1 = new Child();
Child c1 = (Child) p1;   // 编译放行；运行：实际是 Child → 成功

Parent p2 = new Parent();
Child c2 = (Child) p2;   // 编译放行；运行：实际是 Parent → ClassCastException
```

---

## 6. 完整流程图

```text
拿到 T t = (T) x;  S = x 的声明类型
│
├─ 编译期
│   │
│   ├─ 1. T 在 S 的祖先链上？
│   │   └─ 是 → 向上转型，放行 → 进入运行期
│   │
│   ├─ 2. S 在 T 的祖先链上？
│   │   └─ 是 → 向下转型，放行 → 进入运行期
│   │
│   └─ 3. 无父子关系，排除法：
│       ├─ S、T 都是类 → 报错
│       ├─ S 是 final 且 T 不在 S 祖先链上 → 报错
│       ├─ T 是 final 且 S 不在 T 祖先链上 → 报错
│       └─ 其余 → 放行 → 进入运行期
│
└─ 运行期
    ├─ x == null → 成功
    ├─ 实际对象 instanceof T → 成功
    └─ 否则 → ClassCastException
```

---

## 7. 三种转换


| 名称     | 条件                               | 编译期   | 运行期           |
| -------- | ---------------------------------- | -------- | ---------------- |
| 向上转型 | `S` 是 `T` 子类型                  | 自动放行 | 一定成功         |
| 向下转型 | `T` 是 `S` 子类型                  | 强转放行 | 实际是`T` 才成功 |
| 交叉转换 | 无父子关系，但规则允许潜在共同子类 | 强转放行 | 实际是`T` 才成功 |

---

## 8. 边界

以上模型适用于普通类、接口、final 之间的引用转换。


| 场景           | 额外规则                                                                    |
| -------------- | --------------------------------------------------------------------------- |
| 数组           | 协变；元素赋值失败抛`ArrayStoreException`                                   |
| 泛型           | 类型擦除；`Liststring` 到 `Listinteger` 强转可能编译通过但有 unchecked 警告 |
| sealed 类/接口 | 限制潜在子类型，判断更复杂                                                  |

---

## 9. 最终口诀

1. **对象实际类型不变，引用声明类型可变。**
2. **编译期排除“必然失败”：先看继承链是否连通，不连通再用排除法。**
3. **排除法前提：无父子关系。两个类 → 报错；final 堵死 → 报错；有接口参与未堵死 → 放行。**
4. **“潜在”= 规则上可能，不是实际存在。编译器不搜索第三方类。**
5. **放行 = 编译期结束，不是转换终点。运行期还要 `checkcast`。**
6. **运行期只看实际对象：`null` 成功，`instanceof T` 成功，否则异常。**
